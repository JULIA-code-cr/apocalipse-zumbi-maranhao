# Índice de Sobrevivência Zumbi — Maranhão

Análise lúdica, com **dados públicos e reais**, para comparar cinco cidades do Maranhão em um cenário fictício de apocalipse zumbi.

## Ranking

| # | Cidade | Índice de Sobrevivência |
|---|---|---|
| 1 | Imperatriz | **71,8** |
| 2 | Caxias | **60,9** |
| 3 | Balsas | **57,3** |
| 4 | São Luís | **30,0** |
| 5 | São José de Ribamar | **13,9** |

## Indicadores

- **Densidade demográfica** — IBGE, Censo 2022, tabela 4714.
- **Acesso à água** — IBGE, Censo 2022, tabela 6803: domicílios com ligação à rede geral.
- **Infraestrutura de saúde** — MS/DATASUS/CNES, competência 06/2026: leitos hospitalares por mil habitantes.

## Metodologia

`IS = 10 × (0,40·Ndens + 0,30·Nágua + 0,30·Nsaúde)`

As notas de cada indicador são normalizadas de 0 a 10 (min–max entre as cinco cidades). Na densidade, valores menores recebem notas maiores, em escala logarítmica.
